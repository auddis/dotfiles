# Project Context: Dotfiles

## Purpose
This repository contains system configuration files (dotfiles), shell scripts, and setup automation for personal development environments.

## Tech Stack
- **Shell:** Zsh, Bash
- **Tools:** Git, Homebrew, macOS defaults
- **Config Formats:** YAML, JSON, Zshrc, etc.

## Guidelines for Gemini CLI
- **Security:** Critically audit for any hardcoded secrets, API keys, or insecure shell commands.
- **Portability:** Ensure scripts are robust and work across different macOS versions or setups where applicable.
- **Readability:** Prefer clean, commented shell scripts.
- **Tone:** Technical, efficient, and precise.
